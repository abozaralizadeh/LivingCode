Watch it fix a real bug.

Pick a bug. A fresh copy of a tiny sample shop starts up, a visitor hits the bug, and the agent asks an AI for a fix and a test. Then a guard with no AI in it deploys the fix and watches it.

The AI is real, so sometimes it won't find a fix. That's fine. Nothing gets deployed unless the tests and the health checks pass, and the guard can always put the last good version back.

This server has no AI key set yet, so it runs on the scripted fake AI. Everything else is the real thing.

How this demo is locked down

You only pick a bug

Nothing you type reaches the AI or gets run. The three bugs are fixed in the code.

The run has no network

It happens in a sealed process that can't reach the internet. It asks for AI help through a local relay, and only the relay has the key.

The AI has no shell

It can read, search and edit files in its own copy of the shop, and run the tests. That's the whole list.

Thrown away after

Each run gets a fresh folder, deleted when it ends. One run at a time, with a time limit and a daily cap.
